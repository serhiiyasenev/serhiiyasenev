# Repository catalog

Start with the three [selected projects](README.md#selected-projects): **TaskManager**, **BookShop** and **Scheduler**.

This index groups the other 49 public repositories reviewed in October 2026. Labels describe their role in the portfolio, not a production-readiness or seniority rating. Forks, reference adaptations, coursework and related variants are distinguished from the featured application projects. Private repositories are not listed.
